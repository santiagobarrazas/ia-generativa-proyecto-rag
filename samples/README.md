# Documentos de ejemplo

PDFs reales para probar la app: crea un proyecto por carpeta y sube sus archivos en **Conocimiento**.
Sirven también para probar las conexiones entre proyectos (por ejemplo, conectar 01 con 02, que son dos enfoques sobre Parkinson).

Todos son artículos de acceso abierto con licencia Creative Commons Attribution (CC BY), que permite redistribuirlos citando a sus autores.
